## Google Play Console Setup

### Create App in Play Console (First-time instructions)

1. Go to [Google Play Console](https://play.google.com/console)
2. Click "Create app"
3. Fill in:
   - App name
   - Default language
   - App or game
   - Free or paid

### Set Up Store Listing

- App icon (512x512, 1024x1024)
- Feature graphic (1024x500)
- Screenshots (multiple sizes for phones, 7-inch tablets, 10-inch tablets)
- Description (compelling and SEO-optimized)
- Short description
- App category
- Contact details
- Privacy policy URL

### Content Rating

- Complete content rating questionnaire
- This is mandatory for all apps

### App Content

- Target audience
- Ads declaration (if applicable)
- COVID-19 contact tracing (if applicable)
