## Scenario: App Rejection

### Common Reasons:

- Policy violations
- Performance issues
- Security concerns
- Incorrect metadata

### Resolution Process:

- Review rejection reason carefully
- Fix the issues
- Submit updated build
- Respond to review team with changes made

## Scenario: Rollback Needed

### Process:

- Go to Release Management
- Find the problematic release
- Click "Halt rollout"
- Deploy previous working version
- Investigate and fix issues

## Scenario: Security Update Required

### Process:

- Identify vulnerability
- Develop and test fix
- Submit as expedited update if critical
- Notify users about important security update
