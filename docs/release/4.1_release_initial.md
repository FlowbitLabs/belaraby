## Scenario 1: Initial Production Release

### Step 1: Prepare Release

1. In Play Console, go to "Production" track
2. Click "Create new release"
3. Upload App Bundle (.aab file)
4. Add release notes:
   - What's new in this version
   - Bug fixes
   - Improvements

### Step 2: Configure Release

```
Release name: "1.0.0"
Release notes:
  en-US: "Initial release of our amazing app!"
```

### Step 3: Review and Rollout

1. Review all information
2. Click "Start rollout to production"
3. App will be available within hours (usually 2-48 hours)
