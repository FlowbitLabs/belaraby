## Scenario 4: Beta Testing

### Internal Testing

- Quickest way to test (up to 100 testers)
- Almost immediate availability
- Good for team testing

### Closed Testing

- Larger group of testers
- Can have multiple tracks
- Good for pre-release testing with real users

### Process:

- Create internal/closed testing track
- Upload build to testing track
- Add testers via email or Google Groups
- Testers install via Play Store link
