### Scenario 2: Hotfix Release

## When to Use:

- Critical bug affecting many users
- Security vulnerability
- App crash issue

## Process:

1. Increase version code immediately

```yaml
version: 1.0.1+2 # Increment both
```

2. Build and test hotfix

```bash
flutter build appbundle --flavor production
```

3. Expedited review request (if critical)

- In Play Console, mention it's a critical fix
- Request expedited review if available
