# Dashboard Getting Started

The Belaraby Dashboard is a React Admin application for managing content.

## Installation

Install the application dependencies by running:

```sh
cd dashboard
npm install
```

## Development

Start the application in development mode by running:

```sh
npm run dev
```

## Production

Build the application in production mode by running:

```sh
npm run build
```

## Configuration

Update the `.env` file in the `dashboard` directory:

```sh
# Your supabase instance URL
VITE_SUPABASE_URL=
# Your supabase API key. We recommend using the public anonymous key
VITE_SUPABASE_API_KEY=
```
